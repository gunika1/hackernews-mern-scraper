# Hacker News MERN Scraper

A full-stack MERN application that scrapes top Hacker News stories, stores them in MongoDB, and allows authenticated users to bookmark stories.

---

## Features

- Hacker News scraping
- JWT Authentication
- Bookmark functionality
- Protected routes
- MongoDB integration
- Responsive UI
- Full-stack MERN architecture

---

## Tech Stack

Frontend:
- React
- Axios
- Context API

Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

Deployment:
- Vercel (Frontend)
- Render (Backend)
